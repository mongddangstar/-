# 취재원 인터뷰 질문 준비 (기자용)

기자가 벤처투자 생태계 취재원을 만나기 전, **무엇을 물을지** 정할 수 있도록 공신력 있는 최신 자료를 모아
**보고서 + 질문지**를 만든다. 취재 대상은 세 갈래다 — **①투자사(GP: VC·AC·PEF)**, **②기관 출자자(LP)**,
**③스타트업(비상장 피투자기업)**. 결과물은 모바일에서 탭 전환하며 보기 편한 **웹 링크(Artifact)** 로 전달한다.

## 입력 해석

사용자가 대상명과(선택적으로) 관계자명을 준다. 예: "오늘 아주IB투자 박세근 상무 만나",
"오늘 000스타트업 대표 만나", "한국성장금융 000팀장 만나".
- 대상명만 있으면 → 대표·핵심 인물 중심의 보고서를 만든다(관계자 질문은 일반화).
- 관계자명이 있으면 → 그 사람의 프로필·담당 업무·대표 이력·발언을 중심으로 심화한다.
- 동명이인·동명 회사·직책 변화 가능성에 유의하고, 확인 안 되면 결과물에 "미확인"으로 표시한다.

## 워크플로우

### 0단계 — 취재 대상 주체(subject) 유형 판별 (가장 먼저)
브리핑을 만들기 전, 대상이 어느 **주체**인지 먼저 판별한다. 이후 조사 소스·보고서 카드·질문 카테고리가
모두 이 갈래에 따라 달라진다.

| 주체 | 해당 예 | 핵심 성격 |
|------|---------|-----------|
| **① 투자사(GP)** | VC(창투사)·AC(액셀러레이터)·PEF 운용사 | 펀드를 결성·운용해 투자하는 곳. 아래 1단계 세부 유형표 적용. |
| **② 기관 출자자(LP)** | ⓐ 정책 출자기관(모태펀드/한국벤처투자·한국성장금융·국민성장펀드·산업은행), ⓑ 연기금·공제회(국민연금 기금운용본부·사학/공무원연금·교직원/행정/군인공제회·과학기술인공제회·노란우산), ⓒ 민간 금융기관 출자부서(은행·보험·캐피탈, 펀드오브펀드) | GP에 자금을 대는(출자하는) 곳. 출자담당 운용역/팀장이 취재원. |
| **③ 스타트업(비상장)** | 포트폴리오사·피투자기업 | 투자를 받는 회사. 창업자/대표·경영진이 취재원. |

### 1단계 — (투자사일 때) 하우스 세부 유형·상장 여부 식별
대상이 **투자사(GP)** 이면 세부 유형을 판별한다. 유형에 따라 조사 항목과 질문 비중이 달라진다.

| 유형 | 핵심 조사 포인트 | 질문에서 강조할 것 |
|------|------------------|--------------------|
| **VC(창투사)** | 결성 조합·AUM, 주력 섹터, 회수 실적, 모태/성장금융 GP 이력, (상장 시) DART 실적 | 하우스 전략·포트폴리오, 정책펀드, 심사역 개인 전략 |
| **AC(액셀러레이터)** | 보육·초기투자, TIPS 등 정부지원사업, 팁스 운영사 여부, 팁스·개인투자조합 | 초기 생태계, 정부지원사업, 보육 전략 |
| **PEF 운용사** | 블라인드/프로젝트 펀드, 바이아웃·그로스, 회수·드라이파우더, 출자자(LP) | 딜 소싱·회수 전략, 밸류업, 출자 트렌드 |

상장 VC(예: 아주IB투자·에이티넘인베스트·컴퍼니케이 등)는 **DART 전자공시**에서 실적·주요사항을
반드시 확인한다. 대상이 **LP** 나 **스타트업**이면 1단계 대신 아래 "주체별 조사·구성 가이드"를 따른다.

### 주체별 조사·구성 가이드 (보고서 카드 · 질문 카테고리 · 조사 소스)
주체 유형이 정해지면 아래 표대로 **보고서 5개 카드**, **질문 4개 카테고리 세트**, **조사 소스**를 맞춘다.
카드/카테고리의 색상·번호 체계·출처 `[n]` 규칙은 모든 주체가 동일하고, **제목·내용만 주체별로 치환**한다.

**(1) 보고서 5개 카드 (5번째 카드는 주체별 대체형)**

| # | ① 투자사(GP) | ② LP 기관 | ③ 스타트업(비상장) |
|---|-----------|---------|------------------|
| 1 개요 | 하우스 개요(유형·설립·상장·AUM·대표) | 기관 개요(설립·근거법/설립목적·자산규모·조직) | 회사 개요(설립·사업영역·대표·투자단계) |
| 2 동향 | 펀드 결성·투자·회수·인사 | 출자사업 공고·GP 선정·정책 변화 | 투자유치 라운드·제품·인력·파트너십 |
| 3 관계자 | 심사역/임원 프로필 | 출자담당(운용역/팀장) 프로필 | 창업자·경영진 프로필 |
| 4 정책연관 | 국민성장펀드·정책펀드 연관성 | 정책·출자 프로그램(국민성장펀드 등 운용) | 투자유치·주주(VC)·정부지원 |
| 5 실적(대체) | DART·실적(상장) / 펀드·LP구조(비상장) | 자산배분·출자 포트폴리오(주요 GP) | 성장지표·재무(외감 감사보고서 or "비공개") |

**(2) 질문 4카테고리 세트 (주체별로 제목이 다름 — 색상 c1~c4 순서 유지)**

| 카테고리 | ① 투자사(GP) | ② LP 기관 | ③ 스타트업 |
|---|-----------|---------|-----------|
| c1 (현안) | 하우스 현안·이슈 | 기관 현안·출자 이슈 | 회사 현안·이슈(시장·경쟁·규제) |
| c2 (개인) | 관계자 개인·심사역 전략 | 관계자(출자담당) 개인·운용 관점 | 창업자·경영진 개인·비전 |
| c3 (정책) | 국민성장펀드·정책펀드 | 국민성장펀드·정책 출자 방향 | 투자유치·자본조달(+정부지원·모태 피투자) |
| c4 (전략) | 하우스 전략·포트폴리오 | 자산배분·GP 선정 기준·출자 프로그램 | 사업·제품 전략·성장·회수(IPO/M&A) |

**(3) 조사 소스 — 세 주체 모두 공식 홈페이지를 우선 조사한다**
- **① 투자사 홈페이지**: 연혁·운용펀드·팀/심사역·포트폴리오·보도자료·채용(전략 신호).
- **② LP 기관 홈페이지/공시**: 출자사업 공고·GP 선정 결과, 연차보고서·자산배분, 조직도, 보도자료.
  공공기관이면 **ALIO(공공기관 경영정보 공개시스템, alio.go.kr)** 로 재무·인력·임원 보강.
- **③ 스타트업 홈페이지/DB**: 회사소개·제품/서비스·팀·채용·기술블로그·보도자료 + THE VC(thevc.kr)·혁신의숲
  (innoforest)·벤처스퀘어·플래텀(투자유치·성장지표). **외부감사대상이면 DART 감사보고서(재무제표)**,
  KIPRIS(특허), 잡코리아/원티드(인원), 중기부 벤처확인/이노비즈. **동명 회사·법인 주의.**

세부 소스 디렉터리는 `sources.md`(투자·출자기관·스타트업 절)를 참고한다.

### 2단계 — 병렬 자료 조사 (최근 1~2년 우선)
효율을 위해 `general-purpose` 서브에이전트를 **소스별로 병렬 실행**하는 것을 권장한다(대상 개요·뉴스·공시
한 갈래, 관계자 개인 한 갈래 등). 각 갈래에서 다음을 수집한다. **모든 사실에는 반드시 출처 URL과 날짜를 붙인다.**
아래는 공통 뼈대이며, 주체별 우선 소스는 위 "주체별 조사·구성 가이드 (3)"을 함께 본다.

- **대상 공식 홈페이지**(WebFetch): ①투자사=연혁·운용펀드·팀/심사역·포트폴리오, ②LP기관=출자사업 공고·연차보고서·조직도,
  ③스타트업=회사소개·제품/서비스·팀·채용·기술블로그. 세 주체 모두 보도자료·채용은 전략 신호로 확인한다.
- **최근 뉴스**(WebSearch, 1~2년): (투자사) 펀드 결성·투자·회수·인사, (LP) 출자사업·GP 선정·정책, (스타트업)
  투자유치 라운드·제품 출시·파트너십·규제 — 규제·논란 등 시의성 이슈 포함.
- **공시·재무**: 상장 투자사는 **DART OpenAPI로 실적 1차 산출**(아래 별도 절차), 주요사항·지분변동은 공시·언론 보완.
  **스타트업은 외부감사대상일 때만 DART 감사보고서(재무제표)** 조회, 비대상이면 "비공개/미공시"로 표기.
  **LP 공공기관은 ALIO(alio.go.kr)** 로 재무·인력·임원 보강.
- **정부·공공 공식자료**: 모태펀드(한국벤처투자), 한국성장금융, **국민성장펀드**, 중기부·금융위 보도자료,
  KVCA(벤처캐피탈협회) 공시·통계 — GP 선정 이력·정책 방향. (LP 취재 시 특히 핵심)
- **관계자 개인**: 경력·학력, 담당 업무(섹터/펀드·출자 프로그램·사업), 대표 이력(딜/투자유치/정책),
  최근 인터뷰·기고·컨퍼런스 발언(직접 인용문 확보 시 유용).

소스 목록과 각 소스에서 얻을 것은 `sources.md`(투자·출자기관·스타트업 절)를 참고한다.

#### 상장 VC — DART OpenAPI로 실적 정확화 (필수)
상장 VC(창투사)는 실적 수치를 언론 요약이 아니라 **DART 전자공시 OpenAPI 1차 값**으로 산출한다.
인증키는 환경변수 `DART_API_KEY`(crtfc_key)로만 사용하고 **코드·커밋·결과물·로그에 절대 노출하지 않는다.**

1. **corp_code 매핑**: `GET https://opendart.fss.or.kr/api/corpCode.xml?crtfc_key=$DART_API_KEY` (zip→xml).
   종목코드(예: 아주IB투자 `027360`)로 8자리 `corp_code`를 찾는다. (알려진 corp_code면 재사용)
2. **주요계정 조회**: `GET https://opendart.fss.or.kr/api/fnlttSinglAcnt.json`
   `?crtfc_key=$DART_API_KEY&corp_code=<8자리>&bsns_year=<YYYY>&reprt_code=<코드>`
   - `reprt_code`: 사업보고서 `11011` · 반기 `11012` · 1분기 `11013` · 3분기 `11014`.
   - 응답의 `fs_div`(CFS 연결 / OFS 별도)를 구분해 표기. 금융업이라 **영업수익·영업이익·당기순이익·자산총계·자본총계** 중심.
   - 세부가 더 필요하면 `fnlttSinglAcntAll.json`(sj_div=IS/BS).
3. **증감률**: 응답의 `thstrm_amount`(당기)·`frmtrm_amount`(전기)로 전년 대비 계산. 숫자는 콤마 제거 후 파싱.
4. 결과물 DART 카드에 API 값을 넣고 출처를 `DART 전자공시 OpenAPI · <보고서종류> · 조회일 <오늘>`로 명기.
   - `status`가 `000`이 아니거나 키가 없으면 **날조하지 말고** 언론 기반 수치를 유지하되 "DART API 미조회"로 표시.
   - 커밋 전 diff에 인증키가 섞이지 않았는지 반드시 확인.

### 3단계 — 검증·출처 표기
- 사실마다 `(출처: 매체/기관, 날짜, URL)`을 남긴다. 출처 없는 서술은 넣지 않는다.
- 수치·펀드명·인물 경력은 **지어내지 않는다.** 상충하거나 확인 안 된 항목은 "미확인/확인필요"로 명시.
- 발행 시점(오늘) 기준으로 최신성을 재확인한다.

### 4단계 — 결과물 생성 (2탭 모바일 HTML → Artifact)
`template.html`을 복제해 자리표시자(`{{...}}`)를 조사 내용으로 채운다.

- **보고서 탭**: 5개 카드(개요 → 최근 1~2년 동향 → 관계자 프로필 → 정책/투자유치 연관성 → 실적/구조).
  각 카드 제목·내용은 **주체별 조사·구성 가이드 (1) 표**대로 치환한다(투자사=DART·실적, LP=자산배분·출자 포트폴리오,
  스타트업=성장지표·재무). 각 항목에 출처 각주.
- **질문지 탭**: 4개 카테고리별 질문 카드. 카테고리 제목은 **주체별 조사·구성 가이드 (2) 표**대로 치환한다.
  **각 질문에 근거 출처 태그**(어느 사실/기사에서 나온 질문인지)와 우선순위를 붙인다.
  - 대상 주체를 히어로 meta-row의 **주체유형 칩**(투자사 / LP기관 / 스타트업)에 표기한다.
- **출처 번호**: 보고서·질문지의 인라인 각주는 **하나의 번호 체계 `[n]`** 로 통일한다. 인라인 `[n]`은
  누르면 원문으로 바로 연결되게 하고, **두 탭 모두 하단에 번호 매긴 "출처" 목록**을 둔다(각 항목 `id="src-n"`,
  카드 제목은 두 탭 모두 "출처"). 본문 각주 번호와 하단 출처 번호가 어긋나지 않게 맞춘다.

**질문 카테고리(4종, 주체 유형별 세트 — 위 (2) 표 참조):**
- **① 투자사(GP)**: 1) 하우스 현안·이슈 2) 관계자 개인·심사역 전략 3) 국민성장펀드·정책펀드 4) 하우스 전략·포트폴리오
- **② LP 기관**: 1) 기관 현안·출자 이슈 2) 관계자(출자담당) 개인·운용 관점 3) 국민성장펀드·정책 출자 방향 4) 자산배분·GP 선정 기준·출자 프로그램
- **③ 스타트업**: 1) 회사 현안·이슈(시장·경쟁·규제) 2) 창업자·경영진 개인·비전 3) 투자유치·자본조달(+정부지원·모태 피투자) 4) 사업·제품 전략·성장·회수(IPO/M&A)

좋은 질문의 조건: (a) 조사한 구체적 사실에 근거할 것, (b) 예/아니오로 끝나지 않는 개방형,
(c) 기사화 가치가 있는 각(angle)을 물을 것, (d) 민감한 사안은 완곡하되 핵심을 비껴가지 않을 것.

### 5단계 — 저장·발행
1. 채운 HTML을 `reports/{하우스}-{YYYY-MM-DD}.html`에 저장(= Artifact 소스이자 이력).
2. `Artifact` 도구로 발행해 **모바일 웹 링크**를 사용자에게 전달한다.
   - `favicon`는 안정적으로 유지(예: 📋), `title`·`description`은 하우스·관계자 기준으로 지정.

## 원칙
- **정확성 > 분량.** 확인된 사실만, 출처와 함께. 모르는 건 모른다고 표시.
- 최근 1~2년에 무게를 두되 배경 맥락은 간략히.
- 질문은 "기자가 실제로 던질 수 있는" 형태로 다듬는다(추상적 총론 X, 구체적 각 O).
- 정치적으로 민감하거나 확인 안 된 의혹은 단정하지 말고 "확인 질문" 형태로 제시.
