# VC 인터뷰 질문 준비 (기자용)

기자가 벤처투자 생태계(LP–GP–PEF–VC–AC) 관계자를 만나기 전, **무엇을 물을지** 정할 수 있도록
공신력 있는 최신 자료를 모아 **보고서 + 질문지**를 만든다. 결과물은 모바일에서 탭 전환하며 보기 편한
**웹 링크(Artifact)** 로 전달한다.

## 입력 해석

사용자가 하우스명과(선택적으로) 관계자명을 준다. 예: "오늘 아주IB투자 박세근 상무 만나".
- 하우스명만 있으면 → 대표·핵심 심사역 중심의 하우스 보고서를 만든다(관계자 질문은 일반화).
- 관계자명이 있으면 → 그 사람의 프로필·담당 펀드·대표 딜·발언을 중심으로 심화한다.
- 동명이인·직책 변화 가능성에 유의하고, 확인 안 되면 결과물에 "미확인"으로 표시한다.

## 워크플로우

### 1단계 — 하우스 유형·상장 여부 식별
먼저 하우스가 어떤 유형인지 판별한다. 유형에 따라 조사 항목과 질문 카테고리 비중이 달라진다.

| 유형 | 핵심 조사 포인트 | 질문에서 강조할 것 |
|------|------------------|--------------------|
| **VC(창투사)** | 결성 조합·AUM, 주력 섹터, 회수 실적, 모태/성장금융 GP 이력, (상장 시) DART 실적 | 하우스 전략·포트폴리오, 정책펀드, 심사역 개인 전략 |
| **AC(액셀러레이터)** | 보육·초기투자, TIPS 등 정부지원사업, 팁스 운영사 여부, 팁스·개인투자조합 | 초기 생태계, 정부지원사업, 보육 전략 |
| **PEF 운용사** | 블라인드/프로젝트 펀드, 바이아웃·그로스, 회수·드라이파우더, 출자자(LP) | 딜 소싱·회수 전략, 밸류업, 출자 트렌드 |
| **LP(출자자)** | 출자 프로그램, GP 선정 기준, 자산배분, 정책 방향 | 출자 전략, GP 선정, 시장 진단, 정책 |

상장 VC(예: 아주IB투자·에이티넘인베스트·컴퍼니케이 등)는 **DART 전자공시**에서 실적·주요사항을
반드시 확인한다.

### 2단계 — 병렬 자료 조사 (최근 1~2년 우선)
효율을 위해 `general-purpose` 서브에이전트를 **소스별로 병렬 실행**하는 것을 권장한다(하우스 개요·뉴스·DART
한 갈래, 관계자 개인 한 갈래 등). 각 갈래에서 다음을 수집한다. **모든 사실에는 반드시 출처 URL과 날짜를 붙인다.**

- **하우스 홈페이지**(WebFetch): 연혁, 운용 펀드, 팀·심사역 구성, 포트폴리오, 채용·보도자료.
- **최근 뉴스**(WebSearch, 1~2년): 펀드 결성(펀드명·규모·일자), 신규 투자·회수(IPO/M&A), 인사·조직,
  실적, 규제·논란 등 시의성 이슈.
- **DART**(상장 VC): 사업/분기보고서 실적 수치, 주요사항보고서, 최대주주·지분 변동.
- **정부·공공 공식자료**: 모태펀드(한국벤처투자), 한국성장금융, **국민성장펀드**, 중기부·금융위 보도자료,
  KVCA(벤처캐피탈협회) 공시·통계 — GP 선정 이력·정책 방향.
- **관계자 개인**: 경력·학력, 담당 섹터·펀드, 대표 딜, 최근 인터뷰·기고·컨퍼런스 발언(직접 인용문 확보 시 유용).

소스 목록과 각 소스에서 얻을 것은 `sources.md`를 참고한다.

### 3단계 — 검증·출처 표기
- 사실마다 `(출처: 매체/기관, 날짜, URL)`을 남긴다. 출처 없는 서술은 넣지 않는다.
- 수치·펀드명·인물 경력은 **지어내지 않는다.** 상충하거나 확인 안 된 항목은 "미확인/확인필요"로 명시.
- 발행 시점(오늘) 기준으로 최신성을 재확인한다.

### 4단계 — 결과물 생성 (2탭 모바일 HTML → Artifact)
`template.html`을 복제해 자리표시자(`{{...}}`)를 조사 내용으로 채운다.

- **보고서 탭**: 하우스 개요 → 최근 1~2년 동향 타임라인 → 관계자 프로필 → 국민성장펀드/정책펀드 연관성
  → (상장 VC) DART 실적 요약. 각 항목에 출처 각주.
- **질문지 탭**: 아래 4개 카테고리별 질문 카드. **각 질문에 근거 출처 태그**(어느 사실/기사에서 나온 질문인지)와
  우선순위를 붙인다.

**질문 카테고리(4종, 하우스 유형별로 비중 자동 조정):**
1. **하우스 현안/이슈** — 최근 인사·실적·규제·논란 등 시의성.
2. **관계자 개인/심사역 전략** — 담당 섹터·투자 철학·대표 딜·커리어.
3. **국민성장펀드/정책펀드** — 국민성장펀드·모태펀드·성장금융 등 정책자금 관련.
4. **하우스 전략/포트폴리오** — 운용 전략, 주력 섹터, 펀드 결성·회수 계획.

좋은 질문의 조건: (a) 조사한 구체적 사실에 근거할 것, (b) 예/아니오로 끝나지 않는 개방형,
(c) 기사화 가치가 있는 각(angle)을 물을 것, (d) 민감한 사안은 완곡하되 핵심을 비껴가지 않을 것.

### 5단계 — 저장·발행
1. 채운 HTML을 `reports/{하우스}-{YYYY-MM-DD}.html`에 저장(= Artifact 소스이자 이력).
2. `Artifact` 도구로 발행해 **모바일 웹 링크**를 사용자에게 전달한다.
   - `favicon`는 안정적으로 유지(예: 📋), `title`·`description`은 하우스·관계자 기준으로 지정.

## 원칙
- **정확성 > 분량.** 확인된 사실만, 출처와 함께. 모르는 건 모른다고 표시.
- 최근 1~2년에 무게를 두되 배경 맥락은 간략히.
- 질문은 "기자가 실제로 던질 수 있는" 형태로 다듬는다(추상적 총론 X, 구체적 각 O).
- 정치적으로 민감하거나 확인 안 된 의혹은 단정하지 말고 "확인 질문" 형태로 제시.
