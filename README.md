# 취재원 인터뷰 준비 도구

VC·AC·PEF·LP 등 벤처투자 생태계 취재원을 만나기 전, **하우스와 관계자에 대한 최근 1~2년 자료**
(뉴스·홈페이지·DART·정부 공식자료)를 조사·분석해 **보고서**와 **질문지(출처 포함)** 두 탭짜리
모바일 웹 브리핑을 만들어 주는 Claude Code 도구입니다.

## 사용법

Claude Code 세션에서 이렇게 말하면 됩니다.

```
오늘 아주IB투자 박세근 상무 만나
```
또는
```
/vc-interview-prep 아주IB투자 박세근 상무
```

그러면 Claude가:
1. 하우스 유형(VC/AC/PEF/LP)과 상장 여부를 판별하고
2. 홈페이지·최근 뉴스·(상장사면) DART·정부 공식자료(모태펀드·성장금융·국민성장펀드 등)를 조사한 뒤
3. **보고서 탭 + 질문지 탭** 두 탭짜리 모바일 웹 링크(Artifact)를 만들어 줍니다.

- 하우스명만 줘도 됩니다(관계자는 선택).
- 모든 사실에는 출처(매체/기관·날짜·링크)가 붙고, 확인 안 된 항목은 "미확인"으로 표시됩니다.

## 질문지 카테고리 (하우스 유형별 비중 자동 조정)

1. 하우스 현안 · 이슈
2. 관계자 개인 · 심사역 전략
3. 국민성장펀드 · 정책펀드
4. 하우스 전략 · 포트폴리오

## 구성

| 파일 | 역할 |
|------|------|
| `.claude/skills/vc-interview-prep/SKILL.md` | 조사→분석→결과물 생성 워크플로우 정의 |
| `.claude/skills/vc-interview-prep/sources.md` | 한국 벤처투자 생태계 공신력 소스 디렉터리 |
| `.claude/skills/vc-interview-prep/template.html` | 모바일 2탭(보고서/질문지) HTML 템플릿 |
| `reports/` | 취재별 생성 브리핑 HTML 보관(= Artifact 소스이자 이력) |

## 참고
- 브리핑은 공개 자료 기반이며, 발행 시점 기준입니다. 민감·미확인 사안은 단정 대신 "확인 질문" 형태로 제시합니다.
- 결과물의 사실관계는 취재 시 1차 출처로 교차확인하시길 권합니다.
