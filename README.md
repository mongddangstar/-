# 취재원 인터뷰 준비 도구

벤처투자 생태계 취재원을 만나기 전, **대상과 관계자에 대한 최근 1~2년 자료**
(뉴스·공식 홈페이지·DART·정부 공식자료)를 조사·분석해 **보고서**와 **질문지(출처 포함)** 두 탭짜리
모바일 웹 브리핑을 만들어 주는 Claude Code 도구입니다.

취재 대상은 **세 갈래**로, 주체 유형에 따라 조사 소스·보고서 구성·질문 카테고리가 자동으로 달라집니다.

| 주체 | 대상 예 |
|------|---------|
| **① 투자사(GP)** | VC(창투사)·AC(액셀러레이터)·PEF 운용사 |
| **② 기관 출자자(LP)** | 모태펀드·한국성장금융·국민성장펀드·산업은행, 국민연금·공제회, 은행·보험 등 출자부서 |
| **③ 스타트업(비상장)** | 포트폴리오사·피투자기업(창업자·경영진) |

## 사용법

Claude Code 세션에서 이렇게 말하면 됩니다.

```
오늘 아주IB투자 박세근 상무 만나        # 투자사
오늘 한국성장금융 000팀장 만나          # LP 기관
오늘 000스타트업 대표 만나              # 스타트업
```
또는
```
/vc-interview-prep 아주IB투자 박세근 상무
```

그러면 Claude가:
1. **취재 대상 주체(투자사/LP기관/스타트업)** 와 (투자사면) 상장 여부를 판별하고
2. **공식 홈페이지**·최근 뉴스·공시(상장 투자사=DART, 외감 스타트업=DART 감사보고서, 공공 LP=ALIO)·
   정부 공식자료(모태펀드·성장금융·국민성장펀드 등)를 조사한 뒤
3. **보고서 탭 + 질문지 탭** 두 탭짜리 모바일 웹 링크(Artifact)를 만들어 줍니다.

- 대상명만 줘도 됩니다(관계자는 선택).
- 모든 사실에는 출처(매체/기관·날짜·링크)가 붙고, 확인 안 된 항목은 "미확인"으로 표시됩니다.

## 질문지 카테고리 (주체 유형별 세트 자동 적용)

| | ① 투자사(GP) | ② LP 기관 | ③ 스타트업 |
|---|-----------|---------|-----------|
| 1 현안 | 하우스 현안·이슈 | 기관 현안·출자 이슈 | 회사 현안·이슈(시장·경쟁·규제) |
| 2 개인 | 관계자 개인·심사역 전략 | 관계자(출자담당) 개인·운용 관점 | 창업자·경영진 개인·비전 |
| 3 정책 | 국민성장펀드·정책펀드 | 국민성장펀드·정책 출자 방향 | 투자유치·자본조달(+정부지원) |
| 4 전략 | 하우스 전략·포트폴리오 | 자산배분·GP 선정·출자 프로그램 | 사업·제품 전략·성장·회수 |

## 참고
- 브리핑은 공개 자료 기반이며, 발행 시점 기준입니다. 민감·미확인 사안은 단정 대신 "확인 질문" 형태로 제시합니다.
- 결과물의 사실관계는 취재 시 1차 출처로 교차확인하시길 권합니다.
